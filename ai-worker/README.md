# Portfolio AI worker

A Cloudflare Worker that powers the site's "Ask Omar's AI" chat and the fit check. GitHub Pages only serves static files, so every model call goes through this worker, which holds the API key.

**Why Cloudflare Workers:** free tier (100k requests/day), KV for per-IP rate limits, native Turnstile bot checks, and streaming responses. A Vercel function would also work but needs a separate store for rate limiting.

## What it does

- `POST /chat` takes `{ mode: "chat" | "fit", messages, turnstileToken?, session? }` and streams the answer as server-sent events.
- Fetches the site's knowledge base (`/ai/knowledge.json`, generated by `next build` from `data/*.ts`), picks the relevant chunks with BM25, and puts them in a server-side system prompt. The client can't change that prompt.
- Security: CORS allow-list, 20 requests per IP per hour (KV), 1,500-character questions (6,000 for fit check), an output-token cap, and Cloudflare Turnstile on first use followed by a signed one-hour session token.
- Provider-agnostic: `AI_PROVIDER` = `gemini` (default, `gemini-3.5-flash-lite`), `anthropic` (`claude-haiku-5-5`), `openai` (`gpt-6-luna`), or `mock` (no key, for local testing).

## Deploy

```bash
cd ai-worker
pnpm install
npx wrangler login
npx wrangler kv namespace create RATE_LIMIT   # paste the printed id into wrangler.toml
npx wrangler secret put GEMINI_API_KEY        # or ANTHROPIC_API_KEY / OPENAI_API_KEY
npx wrangler secret put SESSION_SECRET        # any random string of 32+ characters
npx wrangler secret put TURNSTILE_SECRET      # from the Cloudflare dashboard (Turnstile -> Add site)
npx wrangler deploy
```

`wrangler deploy` prints the worker URL (e.g. `https://omar-portfolio-ai.<you>.workers.dev`). Then, in the GitHub repo, under **Settings → Secrets and variables → Actions → Variables**, add:

| Variable | Value |
| --- | --- |
| `NEXT_PUBLIC_AI_ENDPOINT` | the worker URL |
| `NEXT_PUBLIC_TURNSTILE_SITE_KEY` | the Turnstile site key |

Push to `main` and the site rebuilds with the AI features on. If `NEXT_PUBLIC_AI_ENDPOINT` is unset, the chat, fit check, and "Ask my AI" buttons are hidden and the rest of the site works as normal.

When creating the Turnstile widget, add `omar-elmetwalli.github.io` (and `localhost` for testing) as allowed hostnames.

## Change the model

Edit `AI_PROVIDER` / `AI_MODEL` in `wrangler.toml`, set that provider's key with `wrangler secret put`, and run `npx wrangler deploy` again. Model IDs were checked against the provider docs on 2026-10-26; check the docs again before changing them.

## Local development

```bash
cp .dev.vars.example .dev.vars    # fill in a key, or set AI_PROVIDER=mock
npx wrangler dev --port 8787
```

In another terminal, build and serve the site against it:

```bash
NEXT_PUBLIC_AI_ENDPOINT=http://localhost:8787 pnpm build
pnpm preview                      # http://localhost:4173/github-portfolio/
```

Tests (mocked upstreams, no network or API cost): `pnpm test`.

## Limits worth knowing

- The free KV tier allows 1,000 writes per day. Each question uses one write, so the worker handles about 1,000 questions a day before KV refuses writes (rate limiting then falls back to allowing requests). For more, move the counter to a Durable Object.
- KV is eventually consistent, so a fast burst can slightly exceed 20 per hour.
